# Solar Bot Docs

This folder keeps project documentation and reference media out of the app code.

## Files

- `WIRING.md` - current hardware wiring and verification guide.
- `WIRING.docx` - legacy editable wiring document.
- `requirements-planner.docx` - planner requirements/reference notes.
- `reference/` - datasheets and exported PDFs.
- `images/` - planning screenshots and UI/reference images.
- `archive/` - preserved old/generated files that should not live in runtime folders.
